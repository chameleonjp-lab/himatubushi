# 暇をつぶそう：共通仕様のDraftと公開手順

この変更は既存ゲームの共通UIとランキング連携をレビューするDraftです。Pages設定変更、マージ、実公開、実APIへの試験送信は行っていません。既存READMEは変更しません。

## 実装と保持範囲

- 公開タイトルは「暇をつぶそう」。ゲーム識別子 `nayuta_no_himatsubushi` は、リポジトリ名 `himatubushi` と綴りが異なっても維持します。既存保存キーやデータの移行・削除は行いません。
- 200個のブロック、破壊 +50点、バー -10点、壁 -5点を保持。整数の点数で、大きいほど上位です。球を失った際の7秒の拡大、球追加・バー変化・10秒単位で加算される速度効果、入力・衝突・出現・難易度・ゲーム終了条件は、この公開準備では変更しません。
- ホームの名前は任意。入力を開始時に固定し、空欄を保存名で補わず匿名で開始します。匿名ではスコアRPCを呼びませんが、既存のランキング読取は行います。元の20 UTF-16コード単位上限を保持し、末尾に残った孤立high surrogateだけを除きます。名前は本人認証ではありません。
- 15言語・各77キーのカタログを追加。保存設定→ブラウザー言語→英語で選択し、ルール・結果・送信状態・順位・操作ラベルなどを翻訳します。切替によるゲーム再開始や点数変更はしません。キー数の一致は全画面や翻訳の自然さの保証ではなく、実端末・ネイティブ確認は残件です。
- ホーム／結果のX共有は現在の結果点数・旧正式URL・`#暇をつぶそう #ゲーム制作` の2タグを使用。黒白ボタンとpopup失敗時だけの手動コピー案内を実装し、自動投稿はしません。実X・referrer挙動は未検証です。
- SEは初期ON・音量50%。保存済みOFF/音量0を尊重し、操作を契機に初期化します。ブロック・壁・バー・アイテムなどの音、非表示・消音時の発音停止、重複制御と失敗の非伝播を実装しています。実音や端末復帰の評価は未実施です。
- 結果アクションをランキングより前に配置し、通信中でも共有・再開・ホーム操作を妨げないようにしています。新しいプレイや新しい読取に古い応答が干渉しないよう世代を確認します。
- 既存のベスト／初回ランキングRPCに `p_limit:30` を渡し、画面も最大30件。読取再試行はスコア送信から分離しています。送信とランキング読取の状態を分け、読取失敗をスコア再送の理由にしません。
- 実際の通常6列ランキングの `rank_no` を表示します。同点 `1,1,3`、API順序、同名の別行を保持し、正のsafe integer以外は不明表示。順位を配列番号で推測しません。最大30件は本人識別済みの30人を保証しません。
- 通常8列ACKを実送信callerで検証。HTTP成功だけで確定せず、形状・送信名前・点数・DESCの整合性を確認します。不明・不正応答でも今回点数を保持し、自動的にスコアを再送しません。

## 契約と未解決の境界

通常ACKは `accepted / result_normalized_name / result_display_name / result_first_score / result_best_score / result_play_count / is_first_play / is_new_best` の8列です。9列の別wrapperは仮定しません。名前のサーバー比較はU+0020の前後除去のみを扱い、新規入力の点数範囲と既存履歴のint4範囲を区別します。

ACK検証は応答の整合性であり、永続保存のreadback、同名別人の識別、本人認証、冪等性の保証ではありません。ランキング表示には既存の数値文字列変換とscore/name別名fallbackが残り、`rank_no` の修正だけで全スキーマ境界が厳密になったとは説明しません。実通信や本番データでの確認は行っていません。

匿名開始の計測は公開スコア送信と別契約です。このPRで推測した計測エンドポイントやDB変更を追加しません。実験場の集計、匿名ポリシー、本人識別と冪等性は関連PR・契約確認として追跡します。
